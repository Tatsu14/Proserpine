PROSERPINE

Supprimer mon compte

Vous pouvez supprimer votre compte Proserpine et les données qui y sont liées à tout moment, vous-même, depuis l'application.

Les étapes

  1. Ouvrez Proserpine et connectez-vous.
  2. Touchez l'onglet Profil, puis Modifier mes informations.
  3. Facultatif : touchez Exporter mes données pour garder une copie de votre historique.
  4. Dans « Zone sensible », touchez Supprimer mon compte.
  5. Lisez le message, continuez, saisissez votre mot de passe, puis touchez Supprimer définitivement.

Si vous n'avez pas l'application sous la main

Les mêmes étapes existent dans la version web : proserpine.vercel.app. Si vous avez créé votre compte avec Google (possible sur le web uniquement), supprimez-le depuis la version web : Google vous demandera de confirmer votre identité.

Ce qui est supprimé

  • votre historique de produits consultés ;
  • votre profil (nom d'utilisateur, adresse e-mail, date de création) ;
  • votre compte de connexion.

La suppression est immédiate et définitive : elle ne peut pas être annulée.

Pour en savoir plus sur vos données, lisez la politique de confidentialité.
